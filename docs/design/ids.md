# ID 规范

## 各集合 _id 格式

| 集合 | _id 类型 | 示例 | 说明 |
|------|----------|------|------|
| users | 带前缀字符串 `u_` | `u_1748453200456def0123456` | 注册时生成，历史 ObjectId 仍兼容读取 |
| practiceSessions | 带前缀字符串 `ps_` | `ps_1748453200456def0123456` | 创建练习时生成，历史 ObjectId 仍兼容读取 |
| practiceAttempts | 带前缀字符串 `pa_` | `pa_1748453200456def0123456` | 每次真实作答生成；URL、反馈和资产都引用此稳定 ID |
| reviewItems | 带前缀字符串 `rv_` | `rv_1748453200456def0123456` | 收录错题/复习项时生成，历史 ObjectId 仍兼容读取 |
| scenarios | 带前缀字符串 `sc_` | `sc_1748453200456def0123456` | 题库离线生成，需稳定可读 ID |
| llmCalls | 带前缀字符串 `llm_` | `llm_1748453200456def0123456` | LLM/图片调用审计日志 |
| feedbacks | 带前缀字符串 `fb_` | `fb_1748453200456def0123456` | 一条结果反馈或全局反馈 |
| 反馈图片资产 | 带前缀字符串 `fi_` | `fi_1748453200456def0123456` | 一张反馈原图，写入 feedback 与 OSS 路径 |
| 练习录音资产 | 带前缀字符串 `rec_` | `rec_1748453200456def0123456` | 每次原声上传生成，写入 attempt 与 OSS 路径 |
| 头像资产 | 带前缀字符串 `av_` | `av_1748453200456def0123456` | 每次头像替换生成，主图与缩略图共用 |

## 前缀格式

```
{prefix}{毫秒时间戳13位}{10位随机hex}
```

- 时间戳天然有序，可按创建时间排列
- 随机 hex 10 位（5 字节），同一毫秒内冲突概率极低
- 生成函数：`server/utils/id_generator.py`；集合 ID 与 `recording_id()` / `avatar_id()` 使用同一格式
- ObjectId 兼容：`server/utils/mongo_ids.py` 只用于读取/更新历史数据，新写入不再生成 ObjectId

业务集合统一使用肉眼可读前缀，避免从日志、OSS key、URL 或审计记录里只能看到无语义 ObjectId。
