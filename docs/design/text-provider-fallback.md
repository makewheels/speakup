# 文字模型服务切换

所有文字业务共用 `services.corrector._get_client()`，返回 `FallbackChat`。
配置按主服务、备用 1、备用 2 排列，目标部署顺序为火山 Agent Plan、阿里云、DeepSeek。
没有完整配置的服务不加入候选列表，语音和媒体服务仍使用各自配置。

`ainvoke` 在接口错误、超时或空文本时切换；`astream` 同时处理首段失败和中途断流。
单家总时限 30 秒，SDK/流式空闲等待为 10 秒，不叠加 SDK 自动重试。
上游故障后进程内冷却 30 秒，到期后的新请求再次优先尝试主服务。
全部服务失败后不在同一次业务调用内重新走整条链。

流式切换通过 `reset` 事件废弃此前文本。评估页面重置进度字符数，两个追问入口清空当前
助手气泡；服务端清空聚合文本，最终只存最后成功服务的完整答案。
每个候选服务接收同一个业务请求的消息，独立标准答案的消息不含学习者回答或纠正历史。

`llmCalls.routing` 保存实际服务槽位与尝试顺序、错误类型；`model` 和生成参数来自成功服务。
冷却状态仅存在当前进程内，重启后清零，不引入数据库或跨进程锁。
