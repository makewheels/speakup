# 标准答案重点讲解设计

## 目标

标准答案不仅给出“可以怎么说”，还应解释其中值得学习的领域词汇和高价值表达。讲解不是整段翻译，也不是针对用户错误的第二套纠正。

## 隔离原则

标准答案及讲解必须由独立请求生成，只允许读取题目白名单快照：场景、任务、要点、难度和语言偏好。请求上下文不得包含用户 transcript、gaps、分数、历史作答或纠正结果。

## 返回结构

```json
{
  "standardAnswer": "Hi, I've had a sharp pain in my lower right abdomen for two days now, and it gets worse after eating. I've had gastritis before, and I'm allergic to penicillin.",
  "standardAnswerNotes": [
    {
      "expression": "a sharp pain",
      "chinese": "一阵尖锐的疼痛",
      "explanation": "sharp 描述突然、明显、像针刺一样的疼痛。"
    },
    {
      "expression": "lower right abdomen",
      "chinese": "右下腹",
      "explanation": "描述疼痛位置时常用 lower/upper + left/right + abdomen。"
    },
    {
      "expression": "gastritis",
      "chinese": "胃炎",
      "explanation": "就医时说明既往病史可用 I've had ... before。"
    },
    {
      "expression": "be allergic to penicillin",
      "chinese": "对青霉素过敏",
      "explanation": "be allergic to + 药物/食物，用于主动告知过敏史。"
    }
  ]
}
```

注意：`penicillin` 是“青霉素”，`aspirin` 才是“阿司匹林”；产品讲解必须避免把两种药物混淆。

## 生成规则

- 最多 4 条，按真实交流价值排序。
- `expression` 必须是标准答案中的连续原文。
- 优先领域词汇、固定搭配、常用句型、容易误解的词义或语用边界。
- `chinese` 给简短自然含义；`explanation` 说明如何使用，不重复翻译。
- 基础词、专有地名和无需解释的普通表达不硬凑。
- 无值得讲解内容时返回空数组，前端不显示区块。
- 医疗、法律等场景只讲语言，不给诊断或专业建议。

## 页面形态

- Standard answer 默认展开并按句分行。
- 答案下方显示紧凑的“重点表达”列表；每项以英文表达为主、中文含义和一句说明为辅。
- 整个标准答案区域仍可手动折叠，但播放按钮位于折叠开关外。
- 重点表达文字属于可选中笔记区域，移动端长按选择后可加入笔记。

## 兼容与验收

- 旧 Attempt 没有 `standardAnswerNotes` 时只显示标准答案，不报错、不留空标题。
- 标准答案请求失败时不阻塞主纠正结果；讲解解析失败时降级为空数组。
- 隔离测试证明请求 payload 中没有 transcript、gaps、历史 Attempt。
- 结构测试验证 expression 是 standardAnswer 的连续片段，最多 4 条，空数组不渲染。
- 医疗示例至少能正确区分 penicillin/青霉素 与 aspirin/阿司匹林。
