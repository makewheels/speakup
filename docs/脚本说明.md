# 脚本说明

本文件说明仓库里两处 `scripts/` 目录的用途。运维/部署命令见 [deploy.md](deploy.md)；评测跑法见 [评测/evals.md](评测/evals.md) 与 `server/evals/README.md`。

## 根目录 `scripts/`

| 脚本 | 用途 | 状态 |
|------|------|------|
| `start-server.sh` | 早期单机部署时在宿主直接 `uv run python main.py` 起后端 | **遗留**：现生产已改用 Docker（见 deploy.md），此脚本仅历史参考，勿用于新部署 |
| `send_feature_email.py` | 从环境变量读取 SMTP/Resend 配置，渲染并发送手机友好的功能完成邮件；可将仓库内受限目录的 PNG/JPG 作为内嵌截图发送；主入口是 `feature-notify.yml` | 当前使用 |

## `server/scripts/`（在 `server/` 下用 `uv run python scripts/xxx.py` 运行）

### 题库 / 场景生成
| 脚本 | 用途 |
|------|------|
| `generate_scenarios.py` | 13 个手写种子场景（slug 幂等），场景文案事实源 |
| `generate_public_scenarios.py` | 按 `data/scenario_taxonomy.yaml` 坐标手动补公共题（生产自动补题后为可选） |
| `sync_public_scenarios.py` | dev→prod 同步公共题 + OSS 图（默认 dry-run，`--execute` 才真写） |
| `migrate_storage_layout.py` | 审计并迁移练习录音、朗读与头像到业务路径 v2；默认只读，生产由对象存储维护 workflow 分阶段执行 |
| `archive_overfilled_public_scenarios.py` | 把超量公共题归档（status=archived） |
| `backfill_scenario_videos.py` | 给存量场景补视频 |
| `seed_free_topics.py` | 自由说话题种子（60 题幂等；`--llm-topup N` 才调 LLM 补；`--prod` 写生产） |
| `preview_scenarios_html.py` | 生成本地场景审阅页 |

### 评测 / 成本 / 调试
| 脚本 | 用途 |
|------|------|
| `check_code_quality.py` | CI 门禁：单文件行数/函数参数数等（与 ruff 互补） |
| `cost_report.py` | 从 llmCalls 聚合成本报告 |
| `corrector_breakdown_html.py` / `llm_breakdown_html.py` | 生成纠错/LLM 调用明细审阅页（三引号 HTML 模板，ruff E501 豁免） |
| `export_feedbacks.py` | 导出用户反馈 |
| `probe_volc.py` | 火山方舟连通性探针 |

> 约定：批量调 LLM/文生图默认一次 ≤5；先 dry-run 验证文案再花钱（见 CONTRIBUTING）。涉及生产的脚本默认 dry-run 或需显式 `--execute/--prod`。
