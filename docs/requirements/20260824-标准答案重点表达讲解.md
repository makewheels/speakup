# 标准答案重点表达讲解

- 状态：待上线
- 当前设计：[../design/20260824-标准答案重点讲解设计.md](../design/20260824-标准答案重点讲解设计.md)

## 问题与目标

标准答案能展示完整说法，但医疗等场景里仍有用户不认识或不会迁移的领域词汇和搭配。需要在标准答案下提供少量重点表达讲解，同时保持与用户纠正链路隔离。

## 决定

- 独立标准答案请求返回 `standardAnswerNotes[]`，只读取题目白名单。
- 每项包含标准答案中的连续英文表达、中文含义和一句用法说明。
- 最多 4 条；没有高价值内容时不显示，避免把整段变成词典。
- 高风险领域只讲语言，不给医学、法律等专业建议。

## Checklist 与验收

- [x] 后端模型、Prompt、解析、落库和 API 透传完成。
- [x] 前端在默认展开的 Standard answer 下显示重点表达。
- [x] 讲解文字可被移动端选中加入笔记。
- [x] 隔离测试证明请求不含 transcript/gaps/历史 Attempt。
- [x] 医疗样例正确解释 `sharp pain`、`lower right abdomen`、`gastritis`、`allergic to penicillin`。
- [x] 明确区分 penicillin（青霉素）与 aspirin（阿司匹林）。
- [x] 旧数据/空 notes 不显示空标题、不报错。
