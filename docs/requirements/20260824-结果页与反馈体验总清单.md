## 统一产品判断

- 练习会话是题目和多轮练习的容器；Attempt 是一次独立作答，必须有稳定 ID，不能用数组下标或 `round` 充当身份。
- 结果页先回答“我刚才在做什么”，再回答“做得怎么样”：题目/场景在前，分数在后，反馈随后。
- 渐进生成只替换预留区域里的内容，不改变模块顺序，不二次滚动，不让用户正在阅读的位置跳走。
- 暂时撤下不可用的发音评测 UI 和评测请求；完整原声仍上传，供本人历史回听。
- 标准答案默认展开；播放是独立操作，不能折叠答案。
- 选中文字加入笔记必须支持桌面鼠标和移动端触摸选区，浮层锚定真实选区。
- 分享只生成页面内可见、可复制的链接，不调用浏览器或系统分享面板。
- 结果页反馈与 Settings 全局反馈共用多图原件上传能力；仅结果页反馈关联具体 Attempt。
- 迁移例句必须离开当前题目的语境；不能真正举一反三时不显示例句。
- 标准答案需要可选的重点表达讲解，帮助用户理解领域词汇和高价值短语。
