# 结果页交互修正

- 状态：待上线
- 关联总清单：[20260824-结果页与反馈体验总清单.md](20260824-结果页与反馈体验总清单.md)

## 问题

- `?result=1` 只表达“这是结果页”，不能定位具体尝试；刷新或分享时容易默认到错误轮次。
- 分数放在题目前，用户先看到评价却还没看到自己回答的题目。
- 渐进加载时模块顺序和滚动位置可能变化。
- Pronunciation 播放的词片段与实际词不一致，当前模块不可用。
- Standard answer 默认折叠，且历史上播放操作曾影响折叠状态。
- 选中文字加入笔记在移动端不稳定，浮层固定在页面底部而不是选区附近。
- Expression feedback 的“另一个例句”仍围绕当前题目，缺少迁移价值。
- Feedback/Share 页尾动作不显眼；Share 会打开系统分享面板，超出用户预期。

## 决定与权衡

- 短期兼容嵌入 Attempt 时先支持具体轮次；Attempt 独立后 URL 最终使用 `?attempt=<pa_id>`。旧 `result=1` 只做兼容入口。
- 页面顺序采用“题目 → 分数 → 反馈”，分数仍使用固定高度占位，兼顾认知顺序与加载稳定。
- Pronunciation 先完整撤下并停止评测请求，不在错误能力上继续修 UI；完整原声上传保留。
- Standard answer 默认展开，仍允许用户手动折叠；播放按钮独立。
- 选区浮层按 Range 的真实矩形定位；触摸结束后多次捕获，以适配移动浏览器选区更新延迟。
- 迁移例句由 Prompt 强制跨语境，后处理继续过滤近似复述；无法迁移就不显示。
- Share 使用页面内链接弹层，只复制 URL，不调用 `navigator.share`。

## 验收标准

- 打开任意具体 Attempt URL，刷新三次都显示同一轮。
- 结果页首屏先见题目后见分数；流完成后用户滚动位置变化不超过 1 px。
- 页面无 Pronunciation 标题/卡片，网络面板无发音评测请求，历史完整录音仍可播放。
- Standard answer 首次渲染即展开，点击播放后仍展开。
- iOS Safari/Android Chrome 长按选词后，按钮出现在选区附近并能保存正确文字。
- 迁移例句明显离开当前任务；没有合格例句时不出现入口。
- Share 点击后留在当前页面，弹层显示 `/s/<token>`，复制板里只有链接。
