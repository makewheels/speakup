# Attempt 独立实体与存储清理

- 状态：待上线（含生产迁移）
- 当前设计：[../design/20260824-尝试实体与对象存储重构.md](../design/20260824-尝试实体与对象存储重构.md)

## 问题与决定

当前 Attempt 嵌入 `practiceSessions.attempts[]`，数组下标/round 同时被用作 URL、反馈和 OSS 身份，无法稳定引用一次作答。决定新增 `practiceAttempts` 集合和 `pa_...` ID；session 只做题目容器，round 只做展示序号。

OSS 和数据库最终不保留错误路径、旧嵌入结构或无用对象：有业务归属的迁移并补引用，无业务用途的删除。

## Checklist 与验收

- [x] 独立集合、ID、唯一索引、双读和新写完成。
- [x] URL、反馈、录音、TTS、追问和分享全部使用 attemptId。
- [x] OSS attempt 目录从轮次号改为 `pa_...` ID。
- [x] 迁移工具提供 audit/migrate/cleanup 和可重复映射。
- [ ] 生产迁移前后 Attempt 数量与业务字段摘要一致。
- [ ] 目标对象字节数、ETag/CRC 与源一致，页面录音可播放。
- [ ] cleanup 后旧嵌入 Attempt、错误 OSS 路径、无用未引用对象均为 0。
- [ ] 删除报告列出对象数、字节数和不可从当前数据库恢复的边界。
