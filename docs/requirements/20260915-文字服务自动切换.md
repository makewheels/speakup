# 文字服务自动切换

## 需求

火山 Agent Plan 优先；服务报错、限流、超时或返回空文本时，依次使用阿里云、DeepSeek。
覆盖评估、独立标准答案、出题、自由说话题、翻译和追问。

## 决策

- 主服务沿用 `CHAT_*`；两级备用用 `CHAT_FALLBACK_1_*`、`CHAT_FALLBACK_2_*`。
- 每级必须同时配置密钥、接口和模型，缺少任一项则跳过。
- 每家请求总时限 30 秒，流式相邻数据等待最多 10 秒，关闭 SDK 内部重试。
- 故障后当前进程冷却 30 秒，后续请求跳过故障服务；冷却结束后恢复原有优先级。
- 流式已输出部分内容时发送 `reset`，清空旧内容再生成，禁止拼接不同服务的回答。
- 用户取消不触发备用调用；三家都失败时保留现有错误提示和独立答案降级。
- 标准答案与学习者反馈继续使用独立消息，切换不改变数据隔离边界。
- 记录实际服务、模型、生成参数和切换错误类型；不记录密钥或上游错误正文。
