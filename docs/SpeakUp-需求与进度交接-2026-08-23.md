## 三、History 视频播放器：已上线

### 现象

用户从 History 进入练习详情后，场景视频播放器非常小，像被限制在页面左上角；播放器控件也挤在小方框里。

### 已确认根因

- `web/src/components/SessionView.jsx` 在有作答记录时，把图片和视频都渲染为 `className="detail-hero-media"`。
- `web/src/App.css` 中 `.detail-hero-media` 被固定为 `width: 80px; height: 80px; flex: 0 0 80px`。
- 同一个 `SessionView` 同时用于本人历史详情和公开分享页，所以修复应同时验证两处。
- 没有作答记录时使用的 `.session-practice-media` 已经是全宽 `16:9`，可参考其结构。

### 已实施修复

1. 只有图片的已作答记录仍保留 hero 内 `80×80` 缩略图。
2. 有视频的已作答记录改为在 hero 下方单独渲染全宽 `16:9` 播放器，不再渲染第二份缩略视频。
3. 视频使用 `object-fit: contain` 和黑色背景，避免裁掉原始画面；图片继续使用 `object-fit: cover`。
4. 本人历史详情和公开分享页共用同一修复逻辑。
5. 已新增回归测试，覆盖“有作答视频使用全宽容器”“只有图片继续使用缩略图”和“分享页视频不进入 hero 缩略框”。

### 已完成自动化验证

## 五、移除地理位置权限

### 已确认根因

- `web/src/main.jsx` 页面启动即调用 `initTheme()`。
- `web/src/lib/theme.js` 的 `fetchLatitude()` 无条件调用 `navigator.geolocation.getCurrentPosition()`。
- 唯一用途是根据纬度估算日出日落，从而自动切换深浅色主题。
- 代码只读取纬度并存入本地存储，没有发现上传服务器的逻辑；但浏览器仍会弹权限框，所谓“静默尝试”并不静默。

### 已实施修复

- 已删除定位调用，不再读取或保存纬度。
- “自动”主题已改为跟随系统 `prefers-color-scheme`；手动浅色/深色保持不变。
- 已监听系统主题变化，自动模式下实时更新。
- 启动时清理旧纬度缓存 key，不破坏已有主题选择。
- 已更新首屏防闪脚本、中英文说明、CSS 注释和 `theme.test.js`。
- 已覆盖现代浏览器与旧版 Safari 的系统主题监听接口；生产构建产物已确认不含定位 API 调用。
- 全量前端测试、覆盖率、lint、CSS 物理行门禁和生产构建均已通过；[PR #168](https://github.com/makewheels/speakup/pull/168) 已通过 CI、合并和流水线部署。

## 六、埋点、用户轨迹与 Trace

### 当前状态

- 线上前端包没有 PostHog、Umami、OpenReplay、HyperDX 等分析 SDK。
- 打开网页只会留下普通 Uvicorn 访问日志；SPA 内部跳转无法形成完整轨迹。
- 登录会更新 `users.lastLoginAt`，鉴权请求会更新 `authSessions.lastUsedAt`，但这不是事件流。
- 练习、笔记、分享、复习和反馈会留下 MongoDB 业务事实，但不能还原每次点击和页面顺序。
- Langfuse 只跟踪 LLM/媒体生成调用，并关联 `userId/sessionId`；没有贯穿浏览器、FastAPI、MongoDB 和 Langfuse 的统一 `trace_id`。
- TTS 的 `X-Api-Request-Id` 是外部语音厂商请求 ID，不是 SpeakUp 自己的链路 ID。

### 数据库边界

- SpeakUp 业务数据使用 MongoDB：`users`、`authSessions`、`scenarios`、`practiceSessions`、`reviewItems`、`feedbacks`、`freeTopics`、`llmCalls` 等。
- 文件存 OSS。
- Langfuse 使用独立的 PostgreSQL、ClickHouse、Valkey 和对象存储。
- 新的高频遥测不要写进 SpeakUp 业务 MongoDB。

### 已调研方案（尚未获准部署）

- 若优先要“一个调试平台”统一页面体验、错误、回放、日志和后端 Trace：倾向 ClickStack/HyperDX（OpenTelemetry + ClickHouse）。
- 若优先要轻量产品统计、页面访问、漏斗和业务事件：Umami + 独立 PostgreSQL 更轻；后端 Trace 仍需 OpenTelemetry/Tempo 或其他追踪后端。
- 当前没有最终产品决定，不要直接安装或开回放。

### 隐私要求

- 只使用不透明内部 `userId`，不要上传手机号、邮箱、Bearer Token、授权码或分享 token。
- 不上传录音、完整转写、笔记正文、AI 答案或请求体。
- 保留并传播 `sourceType=human|ai_test`，避免自动化体验数据污染真人分析。
- Session Replay 默认关闭；如后续启用，必须遮盖输入框、转写、答案、笔记和个人资料，限制采样率、保留期并提供明确用户选择。
- 埋点不需要浏览器地理位置权限。
