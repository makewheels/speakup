# 结果页交互收口并撤下错误发音模块

结果页改为题目在前、稳定分数位在后；开始评估即进入 `?attempt=<pa_id>`，渐进生成不改变模块顺序或二次滚动。表达建议支持短语到整句的上下对照，不再展示重复的整段纠正版；迁移例句必须来自不同情境。

标准答案默认展开且播放不折叠。移动端和桌面端选中文字均可在真实选区附近加入笔记。页尾反馈与分享使用可区分动作色：反馈按需展开，分享只展示可复制链接，并精确打开被分享 Attempt。

发音评测 UI、自动请求和词片段播放全部撤下；完整原声继续按 Attempt 保存供历史回听。旧发音接口统一返回 410，不再产生供应商请求或计费。

验证：Playwright 在 Chromium、Firefox、WebKit、iPhone 13 和 Pixel 7 五个项目共 20 项通过，覆盖题目/分数顺序、稳定滚动、标准答案和页尾动作。
