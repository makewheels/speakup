# fix: 登录成功后回到登录前原页面（backurl）

问题：未登录打开 `/practice?scenario=<slug>` 等受保护页面，被重定向到登录页，登录成功后固定跳首页，原入口（指定题目、会话链接）丢失。

- `ProtectedRoutes` 守卫：跳登录页时携带 `?redirect=<原路径+查询参数>`（URL 编码）。
- `LoginPage`：登录成功后回跳 `redirect`；`safeRedirect` 只接受站内路径——拒绝外链、协议相对路径 `//` 与登录页自身，参数缺失回 `/`。
- 测试：LoginPage 单测新增 4 条（缺参回首页、带查询回指定题、会话路径保留、拒绝外链）；渐进式 E2E 新增「未登录 → 登录 → 回指定题」全流程（5 引擎矩阵全过）。
- 影响面：所有受保护页面（练习/复习/历史/我的）未登录访问都获得同样的回跳能力；已登录用户行为不变。
