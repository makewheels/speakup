# 结果页笔记、独立标准答案与通知

- 时间：2026-08-23 19:52（北京）
- 关联 PR：待创建

## 背景

结果页存在五类已确认问题：笔记由模型自动挑选而不是用户主动摘录；分享必须绕到历史页；标准答案与纠正版过于相似；差距卡字段、颜色和布局混杂；追问输入区过窄。另需准备一条不泄露凭据的功能完成邮件通道，并调研发音、重音和近音词纠正方案。

## 方案与权衡

- **手动笔记**：删除纠正模型的 `note/noteChinese` 产出和后端自动入库。用户在结果页或本人历史详情选中文字后手动加入 `kind=note`；公开分享页不显示操作。本轮不预生成 AI 解释，只保留上下文供后续惰性生成。
- **两个请求**：纠正分支可看用户原话和上轮反馈，只产出纠正、分数和 gaps；标准答案分支严格只看 `title/where/story/mission/points` 或自由说话题。两分支并发，任一分支失败时另一分支仍可返回；标准答案分支不做二次修复请求，保证一次作答。
- **结果页**：分数下方直接分享，优先调系统分享面板，否则复制文案与链接；如果本次刚开启分享后用户取消或系统分享失败，则立即撤回公开状态。中文标签统一为「你说的 / 纠正版 / 标准答案」；用户原话不分句且两端对齐，两个答案按句分行。
- **差距与追问**：类型和短标题合并；「你说 / 这样说 / 为什么」放在同一核心区，移除 Meaning 展示，例句和中文翻译放折叠区。颜色固定为原话警示红、纠正主色、解释中性色。追问输入区占满宽度，发送键放右下角。
- **邮件通知**：新增只能从默认分支手动运行的工作流，支持 SMTP 和 Resend，从 Infisical 专用路径通过 OIDC 取配置，发送手机友好 HTML + 纯文本，不记录收件人或凭据。
- **发音方案**：本轮只做官方资料调研，建议先用专用口语评测引擎试点，现有 ASR 和文本反馈保持不变；未接入 SDK、未购买套餐、未上线。

- 前端全量测试 278 项通过，覆盖手动文字选区笔记、中文标签、差距核心顺序、例句折叠、标准答案单路展示与结果页分享回滚。

## 修复与后续

- 笔记解释暂不实现，后续应在用户打开笔记时按需生成，并明确缓存和失败降级。
- 发音评测进入产品前，先用 200–300 条真人录音跑同一批对照，验收近音词、词重音、误报率、教师相关性、延迟与成本。
- 当前邮箱授权码曾出现在交互记录中，功能验收后应立即轮换，并同步更新 Infisical。
