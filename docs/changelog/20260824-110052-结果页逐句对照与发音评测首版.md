# 结果页逐句对照与发音评测首版

用户提交后立即进入结果页，先看到自己的原句与纠正版生成状态，不再留在录音页等待完整 JSON。纠正返回新增 `sentenceCorrections`，以服务端生成的 `sourceId` 对齐：每个原句在上、对应纠正版在下；纠正版长度可不同或拆成两句，不做字符级强行对齐。旧结果仍以整段配对兼容。

为控制页面长度，独立标准答案和详细 gaps 默认折叠。结果页、历史详情和分享详情统一使用逐句对照组件。

发音评测首版选择腾讯智聆新版：服务端完成 WSS 鉴权、16kHz WAV 转换、句子/段落逐词初筛，以及最多 3 个低分词的模式 4 二次音素/重音诊断。前端在文字反馈完成并上传录音后单独请求评测，展示实际 IPA → 目标 IPA、原音片段、标准音和确定性短建议；供应商失败不影响文字反馈。统一结果写回 `attempt.pronunciation`。

部署增加独立的 `PRONUNCIATION_*` 配置和默认关闭的 feature flag。当前生产密钥库没有口语评测凭据，因此合并部署不会自动启用或产生调用费用；须先开通服务并完成真人录音验证。调研同步纠正了“阿里云没有公开口语评测接口”的旧结论：阿里云是价格和供应商统一性更好的首要备选，若同批 A/B 质量相当则优先切回阿里。

测试覆盖逐句编号对齐、旧结构兼容、腾讯签名与两段式归一化、持久化路由、结果页生成态、发音卡和前端 API。功能完成通知的生产收件人配置同步更正为两个地址，但地址值仍只保存在 Infisical，不写入仓库。
