# 移除定位权限

- 时间：2026-08-23 21:10（北京）
- 关联 PR：#168

## 背景

网站启动时会调用浏览器地理位置 API，只为根据纬度估算日出日落并切换深浅色主题。业务本身不需要位置数据，这会让用户在刚打开网站时看到没有必要且难以解释的权限提示。

## 方案与权衡

- 完全删除定位调用和纬度读取、保存逻辑，不用 IP 或其他方式替代推断位置；
- 自动主题改为采用浏览器标准的 `prefers-color-scheme`，手动浅色和深色选择保持不变；
- React 启动前的首屏脚本与运行时采用相同规则，避免初始主题闪烁或前后不一致；
- 自动模式监听系统外观变化并即时同步，兼容现代媒体查询事件接口和旧版 Safari 接口；
- 启动时只删除旧版本遗留的纬度缓存，不影响已经保存的主题选择；
- 不保留按日出日落切换的兼容开关，因为继续提供该行为仍需要位置或近似位置，与本次隐私目标冲突。

- 前端全量测试：26 个文件、284 项通过；
- 覆盖率：Statements 90.06%、Branches 82.80%、Functions 88.28%、Lines 93.82%；
- ESLint：0 error，保留 23 个既存 warning；

- Vite 生产构建通过；
- 源码及生产构建产物均确认不含定位 API 调用；
- `git diff --check` 通过，独立只读审查未发现阻断项。

## 修复与后续

本次只修改主题所引发的权限请求，不引入产品埋点、位置分析或其他权限。后续若添加任何浏览器权限，必须由明确的用户操作触发，并在触发前说明用途。
