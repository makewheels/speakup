# 记录访问来源：IP 与归属地，并显示在通知里

- 时间：2026-09-19 21:54:17（北京）
- 关联 PR：#213

此前系统完全不记录访问来源，通知里也不知道用户从哪来。

- **记录**：注册时把首次来源写进用户档案（`signupIp` / `signupRegion`）；注册与提交事件入队时 payload 都带 `ip` / `region`
- **归属地**：走离线库 ip2region（Apache-2.0，查城市级），`services/geoip.py` 封装；**不把用户 IP 发给任何第三方**，无 API 调用费
- **IP 来源**：取 `X-Forwarded-For` 首段（Caddy 注入的真实地址），直连时回落 socket 对端
- **展示**：通知明细里排在手机号后面（如「小明 · 138\*\*\*\*1234 · 北京 · 场景「…」· 第 1 轮 · 12:31」）
- **降级**：库文件缺失、查到保留地址或查询异常都返回空串，通知照常发；每个 IP 的结果进程内缓存，库加载失败只试一次

库文件约 11MB 不进 Git：本地用 `server/scripts/fetch_geoip_db.py` 拉取，Docker 构建时自动拉一份进镜像（失败只警告，不阻断构建）。

验证：后端 439 项通过（新增 geoip 解析/降级 7 项与注册来源 1 项），覆盖率 88.81% 与行数、参数门禁通过。
