# Changelog 档案（追加式）

本目录是**详细变更档案**，与根目录 `CHANGELOG.md`（一行式、北京时间倒序）互补：

- `CHANGELOG.md`：每次改动一行式摘要，快速浏览。
- `docs/changelog/<时间戳>-<名字>/README.md`：重要改动的详细记录，含**背景 / 权衡 / 验证 / 修复**，便于日后回溯"当时为什么这么做"。

## 规则

1. **只增不改**：每条记录是一个独立文件夹，写完不再修改；如有后续修正，新开一条记录并互相链接。
2. **文件夹命名**：`<YYYYMMDD-HHMM>-<简短名字>`（北京时间，名字十几个字内，如 `20260819-1014-结果页与自由录入`）。
3. **每个文件夹必须有 `README.md`**，作为该条记录的索引/正文；可附带设计图、数据等附件。
4. **何时写**：对外行为变更、数据模型变更、架构调整、重要修复。纯重构/格式化可不写（CHANGELOG 一行即可）。
5. 设计稿（`docs/design/`）可以修改；changelog 不修改，只追加。

## 模板

```markdown
# <名字>

- 时间：YYYY-MM-DD HH:MM（北京）
- 关联 PR：#NNN

## 背景
为什么要做（用户诉求 / 问题 / 目标）。

## 方案与权衡
做了什么、考虑过哪些替代方案、为什么选这个、放弃了什么。

## 验证
测试 / 覆盖率 / 构建 / 视觉走查 / 线上观察等证据。

## 修复与后续
过程中发现并修的问题；遗留事项。
```
