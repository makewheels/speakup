# 结果页打磨 + 自由录入 + 文档重构

- 时间：2026-08-19 10:14（北京）
- 关联 PR：#156（结果页/深色）、#157（自动笔记）、#158（自由录入）、本文档随 #7 文档重构提交

## 背景
用户反馈一批体验与功能诉求：① 深色主题录音按钮发灰像被禁用、gap 序号徽章浅底白字看不清；② 纠正结果没展示 LLM 返回的 gap 类型等有价值字段；③ 两个答案板块叫法（Native 版本/标准答案）与语义不符；④ 「记为笔记」整句太重，应由 LLM 自动产出短表达；⑤ 想要「自由录入」练习模式；⑥ 文档混乱需重构。

## 方案与权衡
- **深色配色**：根因是组件复用 `--ink` 做背景（深色下反转为浅灰）。新增语义 token `--rec`（录音红，双主题保持红）与 `--gap-num-bg/ink`，而非给单个组件写 dark 覆盖——保持"只覆盖 token"的既有主题架构。
- **gap 字段展示**：复用既有但闲置的 `.fb-gap-cat` 徽章样式展示 category，新增 title/中文意思/例句行；结果页与历史详情页两渲染器同步。
- **改名**：`nativeVersion`→「纠正/Correction」、`standardAnswer`→「Native」。标题纯 i18n 不入库，老数据自动跟随，**无需改库**（比改数据更安全）。
- **自动笔记**：corrector 新增 `note/noteChinese`（≤8 词可复用短表达，宁缺毋滥），后端自动落 `kind=note`；移除整句手动按钮。evals 加 `note_valid` 防回归成整句。权衡：放弃"给多个候选让用户选"，选"自动选最优+事后可删"（用户已确认）。
- **自由录入**：模式切换 + `freeTopics` 题库（按用户去重 `$sample`、池空 LLM 补 20）；事实源为会话快照 `scenario.kind=free`，corrector 切 FREE prompt（不判任务完成、category 不含 task）。自由说会话延迟到点录音才创建（不留空历史）。
- **文档重构**：顶层 `design/` 归入 `docs/原型设计/`；`docs/design/` 按业务模块分组（场景练习/）；新增 `docs/评测/`、`docs/changelog/`（追加式）、`docs/脚本说明.md`；更新 docs/README、AGENTS、CONTRIBUTING。
