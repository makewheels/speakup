# 独立 Attempt、反馈原图与标准答案讲解

每次真实作答新增独立 `practiceAttempts` 文档和稳定 `pa_...` ID；练习会话只保留题目容器职责。纠正 SSE 在开始事件返回 Attempt ID，录音、TTS、追问、结果反馈、复习项和分享链接均关联具体 Attempt。读取链路在生产迁移期间兼容旧嵌入数据。

结果反馈与全局反馈共用多图原件上传：最多 9 张、单张 30 MB，支持 JPG、PNG、WebP、GIF、HEIC/HEIF，不压缩、不转码，保存到私有 OSS 业务路径。结果反馈额外关联 `practiceId + attemptId`。

独立标准答案结构新增 `standardAnswerNotes[]`，只从题目白名单生成少量重点表达讲解，继续与学习者原话、纠正和历史 Attempt 隔离。

验证：后端全量 331 个测试、前端全量 314 个测试通过；反馈图片、Attempt 迁移、标准答案隔离均有新增覆盖。
