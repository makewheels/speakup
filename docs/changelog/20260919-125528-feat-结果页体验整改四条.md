# 结果页体验整改（四条）

- 时间：2026-09-19 12:55:28（北京）
- 关联 PR：#210

按产品所有者实机走查的意见，一次改完四件事：

1. **下线迁移例句**：删掉 gap 卡片里的「See it in a different situation」折叠区，提示词里 `example` / `exampleChinese` 的生成要求（含 schema 与示例）一并删除，解析层不再产出这两个字段，`gap_examples.py` 与其前端判定模块 `gapExamples.js` 删除。历史数据带这两个字段也不再渲染。
2. **追问区与重说区拉开**：`.fb-actions` 给重说 / 下一题区加上分割线与间距，此前它与上方「Ask the coach」紧贴，被读成同一组。
3. **首轮不挂轮次徽章**：结果页顶部的「Attempt #1」只在第 2 次及以后显示，与练习页 `(round ?? 1) > 1` 的既有规则对齐。
4. **补「你说的」区块**：用户原话此前只在评估加载态出现，加载完就消失；现在收进默认折叠的折叠区，展开可看转写全文并回放本次原声。录音优先用本次录制的本地对象 URL，刷新或从历史进入时回落服务端签名 URL（`restoreRecordingUrl` 由此接上，此前是死代码）。

验证：前端 342 项、后端 431 项通过，覆盖率与两端行数/质量门禁通过；新增组件测试覆盖徽章首轮隐藏、折叠区默认折叠与播放器渲染、无录音时降级。
