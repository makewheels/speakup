# 需求档案、存储迁移和 SVG 代码资产规则

新增 `docs/requirements/`，按“问题、目标、方案权衡、决定、checklist、验收、进度”记录可接力需求；`design/` 只保存当前设计事实，`changelog/` 继续平铺，并在新文件名中使用 `feat`、`fix`、`chore` 区分类型，避免按类型拆目录后让同一功能的时间线分散。

新增 Attempt v3 生产迁移工具及对象存储维护工作流，按 `audit → migrate → cleanup` 分阶段执行：复制校验大小、ETag 与可用 CRC，迁移数据库关联，复验后移除旧嵌入结构，并清理超过安全窗口且无数据库引用的受管对象。报告包含对象类别、计划/验证字节数、删除数量和删除字节数。

仓库不再提交 PNG/JPG/GIF/WebP/HEIC 等界面截图或说明图，本次删除 3 张已入库 PNG。需要持久说明图时至少使用可审查 SVG；真实截图只允许在系统临时目录完成当次验收。功能邮件同步改为只接受安全 SVG，并为本次更新新增小体积矢量说明图。

验证：安全 SVG 校验、功能邮件 13 个测试、后端 ruff/代码质量门禁和前端 lint/生产构建通过。
