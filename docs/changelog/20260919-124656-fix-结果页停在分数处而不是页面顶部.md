# 结果页停在分数处，不再回到页面顶部

- 时间：2026-09-19 12:46:56（北京）
- 关联 PR：#209

提交录音进结果页后，页面落在最顶部，分数要往下翻才看得见。`PracticeFeedbackView` 的 useLayoutEffect 里写的是 `window.scrollTo({ top: 0 })`——把 08-17 那版「进入结果页定位到雅思分数」覆盖掉了，这版把它改回来。

- 改为滚到 `.fb-score-anchor`（`block: "start"`）：分数与轮次徽标停在视口顶部，题目卡与媒体留在上方可回看
- 媒体是固定 `aspect-ratio: 1/1`，图片/视频加载不会撑高页面把落点挤偏
- 仍然只在首帧滚一次，流式结束、媒体加载、发音结果到达都不再滚动（原设计保留）

验证：前端 339 项、覆盖率与行数门禁通过；测试断言滚动目标就是分数锚点元素，生产实机确认落点。
