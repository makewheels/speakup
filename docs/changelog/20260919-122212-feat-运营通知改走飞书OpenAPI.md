# 运营通知改走飞书 Open API

- 时间：2026-09-19 12:22:12（北京）
- 关联 PR：#207

原实现走群自定义机器人 webhook，但飞书不提供创建 webhook 的 API——只能在群设置里手动添加、再人工把 URL 搬进 Infisical。这一步一直没落地，线上 `NOTIFY_ENABLED=false` 且 webhook 为空，事件连队都进不了（生产 `notificationEvents` 为 0 条）。改为复用已有自建应用凭据走 Open API。

- 配置换成 `NOTIFY_FEISHU_APP_ID` / `NOTIFY_FEISHU_APP_SECRET` / `NOTIFY_FEISHU_CHAT_ID`（另有 `NOTIFY_FEISHU_BASE_URL`，默认官方地址），四项仍只存 Infisical `speakup/prod/notifications`
- 发送链路：app 凭据换 `tenant_access_token`（进程内缓存，剩余不足 5 分钟重取）→ `im/v1/messages` 按 `chat_id` 发文本，不再使用 webhook
- HTTP 状态与响应体 `code` 双层判错，沿用原有 pending 重试与 5 次上限
- 日志与 `lastError` 的遮蔽目标从 webhook URL 换成 app_secret
- 接收群改为新建的「SpeakUp 运营」群，运营通知与其他项目的飞书推送分开

验证：后端 435 项、覆盖率 89.16%，前端 339 项、覆盖率与构建、两端行数门禁均通过；生产真发一条验证见验收记录。
