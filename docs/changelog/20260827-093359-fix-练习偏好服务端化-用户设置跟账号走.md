# fix: 练习偏好服务端化——用户设置跟账号走，不再存浏览器

问题：练习偏好（难度/目的）只存在浏览器 localStorage，换设备/清缓存后要求重新设置（用户 13800000001 实测反馈）。偏好应是用户设置，不是浏览器设置。

## 后端（事实源）
- `users.practicePreferences = {level, purpose}`；`GET /api/auth/practice-preferences`（未设置 404）/ `PUT`（非法取值 422、跨用户 403）。
- 登录响应携带已设置的偏好（未设置为 null）。

## 前端（缓存 + 对账）
- 练习页挂载时与服务端对账：服务端有值以服务端为准；本地有值而服务端没有（旧版浏览器设置）自动迁移到服务端，设置不丢；两边都没有才出首次选择题。
- 偏好设置页进入时先拉服务端值；修改立即写服务端。
- 登录成功即把响应里的偏好落本地缓存，减少一次往返。
- localStorage 降级为缓存；对账完成前不抽题、不出选择题。
