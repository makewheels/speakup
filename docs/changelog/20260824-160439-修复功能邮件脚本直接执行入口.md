# fix：修复功能邮件脚本直接执行入口

- 时间：2026-08-24 16:04:39（北京）
- 功能通知工作流直接运行 `python scripts/send_feature_email.py` 时，Python 只把 `scripts/` 放入模块搜索路径，导致新拆出的邮件内容模块无法按包路径导入。
- 入口现在根据 `__package__` 同时支持工作流直接执行与单元测试包导入；新增子进程回归测试，确保缺少配置时进入正常校验，而不是在导入阶段退出。
- WebKit/iPhone 会把相同 CSS 滚动位置按设备像素取整为相差 1px；结果页稳定性回归允许这 1px 数值误差，仍会拦截可见回跳。
- 首次带图通知在导入阶段即失败，未发送任何邮件；修复上线后重新触发。
