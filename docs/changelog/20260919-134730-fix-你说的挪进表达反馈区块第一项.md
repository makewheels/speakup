# 「你说的」挪进表达反馈区块，作为第一项

- 时间：2026-09-19 13:47:30（北京）
- 关联 PR：#211

上一版（#210）把「你说的」折叠区放在一句话总结与表达反馈之间，位置上单独悬着、显得突兀。改为**表达反馈区块的第一项**：跟在区块标题下面、gap 列表之前。

- 表达反馈区块的渲染条件从「有 gap 才出现」放宽到加载完成即出现，这样本轮没有 gap 时也能回看原话；无 gap 时的空态提示一并收进该区块
- 区块头右侧的条数在无 gap 时不显示
- 间距调整：折叠区上方由区块头的 `margin-bottom` 提供，自身只压下方 12px

验证：前端 342 项、E2E 60 项（3 引擎 + 移动端视口）通过，覆盖率与行数门禁通过；生产实机确认折叠区落在「表达建议」标题下方第一项。
