# 运营通知两类事件都带手机号

- 时间：2026-09-19 13:57:39（北京）
- 关联 PR：#212

练习提交的通知此前只有昵称，重名时分不清是谁。现在注册与提交都带脱敏手机号（沿用 `138****1234` 的脱敏规则，手机号不完整进消息）。

- 取用户信息从只查昵称改为一次查 `nickname` + `phone`（`_user_brief`），提交事件的 payload 增加 `phone`
- 卡片布局试过表格（卡片 JSON 2.0 的 `table`），实机看下来太长、不如平铺好读，最终保持分块逐行平铺，只把手机号加进每一行

验证：后端 431 项、前端 342 项通过，覆盖率与两端门禁通过；生产群发预览确认两类事件都显示脱敏手机号。
