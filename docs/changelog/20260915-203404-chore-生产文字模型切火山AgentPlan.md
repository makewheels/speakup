## 背景

生产文字评估此前走 DeepSeek 官方（`api.deepseek.com/v1` + `deepseek-v4-flash`）。按用户决定，文字、配图、视频统一收口到火山方舟 Agent Plan 的同一个 key，文字模型用 `deepseek-v4.1-flash`。

## 改动

- Infisical `speakup/prod/llm` 与 `speakup/dev/llm`：`CHAT_API_KEY` 指向 Agent Plan key（prod 原本只在 `IMAGE_*` / `VIDEO_*` 上用它），`CHAT_BASE_URL` = `https://ark.cn-beijing.volces.com/api/plan/v3`，`CHAT_MODEL` = `deepseek-v4.1-flash`，`CHAT_THINKING` 保持 false。
- `services/llm_audit.py`：价格表补 `deepseek-v4-1-flash`。火山响应里的模型名是点转横线后的形式，按响应名匹配才不会落到 fallback；Agent Plan 额度内按 0 记。
- `server/config.py` 与 `server/.env.example` 的 CHAT 默认值同步；AGENTS / README / deploy / docs-README / scenario-mode 的模型描述同步。

## 代码无需改动

`corrector.thinking_extra_body` 对 `volces.com` 已走 `{"thinking": {"type": "disabled"}}`，Agent Plan 实测认这个格式（`reasoning_tokens=0`），短 JSON 任务不会被思考拖慢。

## 验证

- 本地端到端（`sourceType=ai_test` 账号走 `/api/correct/stream`）：SSE usage 事件 `model=deepseek-v4-1-flash`，标准答案、gaps、progress 全部正常；流式首 token 0.77s，标准答案 1.2s。
- regression 评测（12 条 × 3 trials）：pass@3 11/12、pass^3 9/12。3 条未过——2 条 2/3 偶发，1 条是 category 判 grammar/naturalness 的边界。明细见 [docs/评测/evals.md](../评测/evals.md)。
- 门禁：server pytest 390 passed（覆盖率 88%）、ruff、code-quality；web 337 passed、覆盖率门槛、build。

## 注意

prod 的 `CHAT_API_KEY` 原值（DeepSeek 官方）已被覆盖，旧值可在 Infisical 该 key 的版本历史里找回；如需回滚到 DeepSeek 官方，恢复 `CHAT_*` 三个值后重跑流水线即可。
