# 历史视频播放器

- 时间：2026-08-23 20:40（北京）
- 关联 PR：#166

## 背景

History 列表进入练习详情后，带控制条的场景视频被显示成页面左上方的小方块，无法正常查看画面和使用播放器。相同展示组件也用于公开分享页，因此分享记录存在同样问题。

## 方案与权衡

根因是已有作答的图片和视频共用 `.detail-hero-media`，而该容器固定为 `80×80`。修复后：

- 有视频且已有作答时，将视频移到标题区下方的全宽 `16:9` 容器；
- 图片-only 记录继续使用 `80×80` 缩略图，保留详情标题的紧凑布局；
- 本人详情的分享状态栏仍紧贴标题，视频排在其后，避免降低分享入口可见性；
- 全宽视频使用 `object-fit: contain` 和黑色背景，优先展示完整画面；图片继续使用 `cover`；
- History 详情和公开分享页继续复用 `SessionView`，避免两套布局再次漂移。

没有通过简单放大 `.detail-hero-media` 解决，因为那会同时放大图片缩略图、挤压标题和分享操作，也会让带控制条的视频继续依附在不合适的 hero flex 布局中。
