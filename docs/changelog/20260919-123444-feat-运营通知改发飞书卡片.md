# 运营通知改发飞书卡片

- 时间：2026-09-19 12:34:44（北京）
- 关联 PR：#208

纯文本通知信息密度低、扫读费劲。改为发飞书卡片（`msg_type=interactive`）：蓝色标题栏报「SpeakUp 动态 · 月-日 时:分」，每个事件类别一个分块，块首加粗带图标（👤 新注册 / 🎤 练习提交），明细逐行列出。

- `build_message`（纯文本）换成 `build_card`（卡片 JSON），合并窗口、折叠上限、脱敏逻辑不变
- 发送改用 `interactive` 类型；token 获取与错误判定沿用上一版
- 标题栏给日期与时分，明细只给时分，省一列重复的日期

验证：后端 435 项、前端 339 项、覆盖率与两端门禁通过；生产群预览一条确认渲染效果。
