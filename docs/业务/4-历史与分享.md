# 历史与分享

本文记录 History 列表、本人历史详情与公开分享页当前已实现的产品行为。

## 页面与权限

| 页面 | 路由 | 行为 |
|------|------|------|
| 历史列表 | `/history` | 只展示当前登录用户已有作答的练习记录 |
| 本人历史详情 | `/history/:practiceId` | 查看场景、各轮作答、录音和反馈；支持分享、追问与手动摘录笔记 |
| 公开分享页 | `/s/:token` | 无需登录即可查看已公开的练习结果；不提供付费朗读、追问或笔记写入 |

分享由记录所有者显式开启，结果页可直接发起分享，不需要先进入 History。首次分享被取消或发送失败时，前端会撤销刚开启的公开状态。

## 场景媒体

- 场景只有图片时：已有作答的详情页在标题区显示 `80×80` 紧凑缩略图。
- 场景有视频时：已有作答的本人详情和公开分享页均在标题区下方显示内容区全宽的 `16:9` 播放器，不把带控制条的视频塞进缩略框。
- 视频使用 `object-fit: contain`，避免裁掉原始画面；容器空余区域使用黑色背景。
- 视频可使用场景图作为 poster；媒体加载失败时由 `PracticeMedia` 负责图片回退或隐藏无效媒体。
- 尚无作答的公开预览继续使用同一个全宽媒体容器。

## 多轮作答

- 默认选中最新一轮；有多轮时显示轮次切换。
- 每轮展示用户原话、纠正版、独立标准答案、差距项、录音与已保存的追问记录。
- 本人详情仅允许在最新一轮继续追问；公开分享页始终只读。

| 文件 | 职责 |
|------|------|
| `web/src/pages/HistoryPage.jsx` | 历史列表 |
| `web/src/pages/SessionDetailPage.jsx` | 本人详情的数据读取、分享和追问 |
| `web/src/pages/SharePage.jsx` | 公开分享数据读取 |

| `web/src/components/practice/PracticeMedia.jsx` | 图片、视频与失败回退 |
| `server/routes/practice_sessions.py` | 历史、详情及分享 API |
