# 结果页（发音评测已撤下）

## 当前用户流程

用户提交转写文本后，服务端先保留独立 Attempt 并通过 SSE 返回 `attemptId`；浏览器随即进入 `?attempt=<pa_id>` 结果页，不在录音页等待完整 JSON。旧 `?result=1` 和数字轮次只作兼容入口，打开后会规范化为稳定 URL。

结果页从上到下固定为：

1. 当前模式、题目和场景媒体；
2. IELTS 分数、轮次和一句话总结；
3. 「表达建议」：`gaps[]` 是唯一纠正主体，最多 3 条；
4. 默认展开的「标准答案」及必要的重点表达讲解；
5. 追问教练和重说 / 下一题；
6. 页尾并排的「反馈 / 分享」动作。

进入结果页时，题目、空分数位和已知原话一次性建立稳定骨架。流式文字只填充预留区域；页面只在结果首帧绘制前回到顶部，流结束和媒体加载都不会再次改变滚动位置。

`nativeVersion`、`sentenceCorrections` 和整段纠正版不再由新结果生成或展示。每条 gap 可以覆盖短语或整句话：

- `original` 是学习者原话中的连续片段；只有完全漏说的信息允许为空；
- `better` 与 `original` 表达范围相同，按「你说的 / 这样说」上下对照；
- 同一句里的相关问题尽量合为一条，避免碎成一两个词；
- `example` 只有在能把同一规律迁移到不同情境时才展示，重复本题或近似复述时不展示。

「标准答案」是独立一级标题，正文默认展开；播放按钮不会触发折叠。重点表达讲解只解释值得学习或可能阻碍理解的词组，不机械拆解每个普通词。

用户在结果文字中选中内容时，「加入笔记」浮层锚定实际选区，并同时支持鼠标选择与移动端 selection 事件。反馈默认收起，点击页尾按钮后才出现；结果页反馈绑定当前 `attemptId`。分享只展示可复制链接，不调用系统分享面板，且链接中的 `attempt` 参数会打开被分享的准确轮次。

## 发音评测当前状态

发音评测 UI 和自动请求已全部撤下。录音上传完成后只保存本轮完整原声，供本人在历史页回听；不会裁词、不会请求腾讯或其他评测供应商，也不会产生评测计费。

所有 owner/share 发音评测及片段路由统一返回 `410 Gone`，录音上传固定返回 `pronunciationEnabled=false`。供应商适配代码与关闭状态配置暂时保留，只有完成同一批真实录音的时间轴、片段归属和结果可理解性验收后，才可以另立需求重新开放。

浏览器原声按实际 MIME 保留 WebM/M4A/OGG/WAV 原件，不转存裸 PCM。MediaRecorder 不能跨浏览器稳定输出 PCM，裸 PCM 也缺少采样率、声道等容器元数据且不能直接供网页播放；未来如恢复评测，应在服务端按请求临时规范化，不新增永久副本。
