# 数据埋点（Umami）

SpeakUp 使用自建 [Umami](https://umami.is) 做产品统计（无 cookie、不采集设备指纹以外的信息），部署在 services 机，独立子域 `https://umami.a4.fit`（Caddy 自动证书），前端 `web/src/lib/analytics.js` 只在生产构建注入脚本，本地 dev 完全不打点。

## 事件字典

| 事件 | 触发时机 | 属性 |
|---|---|---|
| （pageview，自动） | 首次加载与 SPA 路由变化 | umami 自动 |
| `practice_recording_started` | 录音成功开始（麦克风已打开） | `mode`（scenario/free）、`userId` |
| `practice_result` | 评估完成且反馈可用 | `mode`、`score`、`gaps` 数、`round`、`userId` |
| `result_shared` | 结果页分享成功（系统分享或复制链接） | `method`（shared/copied）、`userId` |
| `gap_saved` | 差距卡加入错题本成功 | `userId` |
| `note_added` | 结果文字手动摘录保存成功（重复保存不记） | `userId` |
| `followup_asked` | 追问教练发出一个问题 | `userId` |

## 隐私边界

- 只使用不透明内部 `userId`；不上传手机号、邮箱、Bearer Token、分享 token。
- 不上传录音、完整转写、笔记正文、AI 答案或请求体；事件属性只有计数/分数/模式等标量。
- 不开 Session Replay；Umami 本身无回放能力。
- 不请求浏览器地理位置权限。
- 登录态用户才产生 `userId` 属性；未登录访问者只有匿名 pageview。

## 运维

- compose：服务器 `/opt/umami/docker-compose.yml`（umami + 独立 postgres:16，数据卷 `umami-db-data`），desired-state 见 infra 仓库 `services/umami/`。
- 路由：Caddy 独立站点块 `umami.a4.fit` → `umami:3000`（DNS A 记录指向 services 机）。
- 管理后台：`https://umami.a4.fit/`，默认 admin 密码已在首次部署时轮换，凭据位置见 infra `inventory/secrets.md`。
- 数据库与 SpeakUp 业务 MongoDB 完全隔离；高频遥测不写业务库。
