# 9. 练习偏好（难度与目的）

> 数据契约事实源：`docs/design/schema.md` users 集合。

## 是什么
练习偏好（难度 level × 目的 purpose）决定抽题方向。它是**用户设置**，存在服务端、跟账号走，换设备、换浏览器、清缓存都不丢。

## 当前行为
- **首次练习**：没设置过偏好的用户进入练习页会先看到选择题（目的 + 难度），选完开始练习并保存。
- **保存与读取**：`PUT /api/auth/practice-preferences` 写入 `users.practicePreferences`；`GET` 读取；非法取值 422，跨用户 403，未设置 GET 返回 404。
- **登录即带**：登录响应携带已设置的偏好，前端直接落缓存，减少一次往返。
- **对账与迁移**：练习页挂载时以服务端为准对账；本地浏览器有旧设置而服务端没有时自动迁移到服务端（老用户无感升级，设置不丢）。
- **修改入口**：我的页 → 设置区 → 练习偏好；修改立即生效于下一次抽题。
- **影响面**：偏好只影响随机抽题方向；指定题目入口（`?scenario=`）、自由说、已有会话均不依赖偏好。

## 历史说明
2026-08-27 之前偏好只存浏览器 localStorage，换设备会要求重新设置；现已服务端化，本地存储降级为缓存。
