# 自由录入（自由说）

练习页除「场景题」外的第二种练习模式：**自由说**——用户围绕一个日常话题（或完全不要话题）用英语自由发挥，AI 只做语言纠正，不判任务完成度。

## 模式与入口

- 练习页顶部有模式切换器：**场景题 / 自由说**（`PracticeModeSwitch`）。模式写入 URL（`/practice?mode=free`），刷新可还原。
- 自由说流程：
  1. 进入自由说 → `GET /api/free-topics/next?userId=` 抽一个**该用户没说过**的话题，展示话题卡（英文话题 + 中文释义）；
  2. 用户可点「换一个话题」重抽，或点「不用题目，随便说」直接进入无话题自由说；
  3. 点录音才创建 practice session（`mode:"free"`，快照 `freeTopicId`/`freeTopic`）——没开口不留空记录；
  4. 录音 → 转写 → 评估复用现有链路，`POST /api/correct/stream` 带 `mode:"free"`。
- 结果页复用 `PracticeFeedbackView`：自由说的 `standardAnswer` 可能为空（空时不渲染标准答案卡）；用户可选中任何结果文字手动加入笔记。结果页「下一个」在自由说下变成「下一个话题」。
- 追问教练、错题自动收录、选中文字手动加入好表达笔记、录音回放等行为与场景题一致。

## AI 纠正方式（与场景题的差异）

corrector 按会话快照 `scenario.kind == "free"` 走 `FREE_SYSTEM_PROMPT`（见 `services/corrector_prompts.py`）：

- **不判任务完成度**：没有 mission/points 检查，gap 的 category 只用 `grammar / naturalness / vocabulary / register`，绝不出现 `task`（解析层兜底：free 模式下 task 归一为 naturalness）；
- **逐点纠正（gaps）**，不整段重写；gaps ≤4 条；
- `nativeVersion` = 把用户原话改地道（保留全部意图）；
- `standardAnswer` 由独立请求只根据 `freeTopic` 生成；完全无话题时没有可用题目快照，因此可为空；
- `score/progress` 逻辑与场景题相同；纠正模型不再生成 `note/noteChinese`。重说（第 2 轮起）用 `FREE_RETRY_PROMPT`（progress 判定去掉任务措辞）。

## 话题题库（freeTopics）

```json
{
  "_id":        "ft_...",
  "slug":       "your-favorite-breakfast",   // 幂等键（话题文本 slug 化）
  "text":       "Your favorite breakfast",   // 英文话题提示（≤12 词短句）
  "zh":         "你最喜欢的早餐",             // 中文释义，可空
  "status":     "active | archived",
  "sourceType": "seed | llm",                // 种子脚本手写 / LLM 补题
  "createdAt":  datetime
}
```

- **抽题**（`services/free_practice.py`）：从 `status=active` 且不在「该用户已说过」集合里随机抽一个。
  已说过 = `practiceSessions` 里 `mode=free` 且 `attempts.0` 存在的 `freeTopicId`（建会话没开口不算说过）。
- **自动补题**：池子抽空时先调 LLM 一次批量生成 20 个（`generate_free_topics`，单次上限 20），slug 幂等去重后入库再抽；补题失败则接口 404，前端提示后仍可无话题自由说。
- LLM 调用走 corrector 同款客户端 + `audited_invoke`（kind=`free_topic_gen`，全量 I/O 进 llmCalls/Langfuse）。

## practiceSessions 变更

```json
{
  "mode":        "scenario | free",   // 旧数据无此字段按 scenario 归一
  "freeTopicId": "ft_...",            // 自由说话题 id，可空（无话题自由说）
  "freeTopic":   "Your favorite breakfast",  // 话题文本快照，可空
  "scenarioId":  "",                  // 自由说无场景
  "scenario":    { "kind": "free", "title": "话题或「自由说」", "freeTopic": "...", ... }
}
```

- 自由说会话 `kind="free"`、`title`=话题文本（无话题时「自由说」），历史列表标题直接用；
- attempts 每条也带 `mode`/`freeTopic` 快照（`routes/correct.py` 落库）。

## API

| 方法 | 路径 | 说明 |
| ---- | ---- | ---- |
| GET  | `/api/free-topics/next?userId=` | 抽一个没说过的话题；池空自动补题；无题且补题失败 404。鉴权：token 用户 == userId |
| POST | `/api/practice-sessions` |  body 增加可选 `mode/freeTopicId/freeTopic`；`mode:"free"` 时不校验 scenarioId |
| POST | `/api/correct`、`/api/correct/stream` | body 增加可选 `mode/freeTopic`，透传落 attempt；prompt 模式实际由会话快照 `kind` 决定 |

## 历史区分

历史页与详情页按 `session.mode === "free"` 打「自由说」徽章（i18n：`history.freeBadge`）；自由说无场景图，缩略图走占位图标。旧数据无 `mode` 字段按场景题渲染，不显示徽章。

## 种子脚本

`server/scripts/seed_free_topics.py`：内置 60 个手写日常话题（英文+中文），按 slug 幂等 upsert。

```bash
cd server
uv run python scripts/seed_free_topics.py                 # 塞 dev（MONGO_URI），幂等可重跑
uv run python scripts/seed_free_topics.py --llm-topup 40  # 额外调 LLM 补 40 个到约 100（真调外部 LLM）
uv run python scripts/seed_free_topics.py --prod          # 塞生产（PROD_SYNC_MONGO_URI，另行执行）
```

默认**执行插入**（幂等）并打印新增数；不带 `--llm-topup` 不调外部 LLM（测试/CI 安全）。
