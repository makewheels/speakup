# 主题设置

本文记录 SpeakUp 深浅色主题当前已实现的行为和隐私边界。

## 三种模式

| 模式 | 行为 |
|------|------|
| 自动 | 默认模式，跟随操作系统或浏览器的 `prefers-color-scheme`；系统外观变化时立即同步 |
| 浅色 | 始终使用浅色，不受系统变化影响 |
| 深色 | 始终使用深色，不受系统变化影响 |

用户选择存于浏览器本地的 `english-speak-theme-mode`。没有保存手动选择时即为自动模式。

## 首屏与运行时

- `web/index.html` 在 React 启动前读取手动选择或系统外观，先设置 `data-theme`，避免页面闪烁。
- `web/src/lib/theme.js` 在应用启动后接管主题，并监听系统深浅色变化。
- 主题变化会同步更新页面根节点和 `theme-color`，使浏览器顶部区域与页面一致。
- 设置页选择自动、浅色或深色后立即生效。

## 隐私边界

- 主题功能不调用 `navigator.geolocation`，不会请求浏览器地理位置权限。
- 不读取经纬度，不向服务器上传位置，也不按 IP 推断位置。
- 旧版本曾为日出日落估算保存 `english-speak-theme-lat`；新版本启动时会删除这项遗留本地缓存。

## 代码位置

| 文件 | 职责 |
|------|------|
| `web/index.html` | 首屏防闪主题脚本 |
| `web/src/lib/theme.js` | 模式持久化、主题解析和系统变化监听 |
| `web/src/pages/ProfilePage.jsx` | 设置页主题选择 |
| `web/src/lib/theme.test.js` | 主题行为与不请求定位的回归测试 |
