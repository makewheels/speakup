# 7. 账户资料

## 当前行为

用户首次用手机号登录时，系统生成 `User` 加手机号后四位的默认昵称。登录后可在「我的」页头像旁点击「编辑」，直接修改昵称，不需要进入独立页面。

- 昵称长度为 1–24 个字符，支持中英文、数字与普通空格；
- 服务端去除首尾空白，并把连续空白合并为一个空格；
- 保存需要有效 Bearer Token，只能修改当前登录用户；
- 保存成功后立即更新头像首字符、页面昵称和浏览器本地登录态；
- 刷新或重新登录后从数据库读取已修改的昵称；
- 保存失败时保留编辑框与当前输入，用户可以直接重试或取消。

## 接口

| 方法 | 路径 | 行为 |
|---|---|---|
| `POST` | `/api/auth/login` | 登录或创建用户，返回当前昵称与会话 Token |
| `PATCH` | `/api/auth/profile` | 鉴权后更新当前用户昵称，返回规范化后的昵称 |

`sourceType`、手机号和登录会话不会因为修改昵称而变化。
