# 7. 账户资料

## 当前行为

用户首次用手机号登录时，系统生成 `User` 加手机号后四位的默认昵称。「我的」页顶部资料卡用于展示，点击整张卡片进入独立的「编辑个人信息」页。

编辑页按资料类型分开处理：

- **头像**：支持 JPG、PNG、WebP，最大 5 MB；前后端都会校验，服务端按文件签名识别真实类型，不接受 SVG。选择文件后立即上传，成功后同步更新个人页和浏览器本地登录态；可点击「恢复默认头像」改回昵称首字符。
- **昵称**：长度为 1–24 个字符，支持中英文、数字与普通空格；服务端去除首尾空白，并把连续空白合并为一个空格。保存失败时保留当前输入，方便直接重试。
- **手机号**：仅脱敏展示，并明确标记「暂不可修改」。当前所有资料写接口都不接受手机号字段，未来开放时再单独设计验证流程。

头像原文件存阿里云 OSS 私有桶，用户记录只保存 `avatarKey` 和用于刷新缓存的 `avatarVersion`。前端使用版本化应用地址读取，应用再跳转到一小时有效的 OSS 签名 URL；不会把签名 URL 写入数据库。

头像、昵称的保存都需要有效 Bearer Token，只能修改当前登录用户。刷新或重新登录后，登录接口会返回已持久化的昵称和头像地址。

## 接口

| 方法 | 路径 | 行为 |
|---|---|---|
| `POST` | `/api/auth/login` | 登录或创建用户，返回当前昵称、头像地址与会话 Token |
| `PATCH` | `/api/auth/profile` | 鉴权后更新当前用户昵称，返回规范化后的昵称 |
| `POST` | `/api/auth/profile/avatar` | 鉴权后上传并替换当前用户头像 |
| `DELETE` | `/api/auth/profile/avatar` | 鉴权后恢复默认头像，并尽力清理 OSS 原文件 |
| `GET` | `/api/auth/avatar/{userId}` | 版本化头像地址，跳转到私有 OSS 的短效签名 URL |

`sourceType`、手机号和登录会话不会因为修改资料而变化。
